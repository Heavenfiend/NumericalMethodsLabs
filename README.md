# Лабораторные работы по численным методам

Вариант 10. Реализации на Python.

## Установка зависимостей

```powershell
py -m pip install -r requirements.txt
```

## Лабораторная работа 1

Программы и входные данные находятся в `Lab1/`:

- `task1_lu.py` — LU-разложение.
- `task2_tridiagonal.py` — метод прогонки.
- `task3_iterative_methods.py` — методы простой итерации и Зейделя.
- `task4_jacobi_rotation.py` — метод вращений Якоби.
- `task5_qr.py` — QR-разложение и поиск собственных значений.

Например, запуск из корня репозитория:

```powershell
py Lab1/task5_qr.py
```

Входные данные читаются из текстовых файлов в папке `input/` соответствующей лабораторной.

## История

Тег `lab1` отмечает версию с первой лабораторной работой.
